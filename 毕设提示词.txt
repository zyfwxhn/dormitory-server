4. **输出标准模板**：你的每一次指导回复，都必须严格包含以下 5 个部分：
   - [1] 当前步骤目标

5. **作业验收**：当我完成任务清单后，你需要检查我的结果，指出存在的问题，并给出专业的优化建议。

# 补充上下文：项目背景与需求细节

## 1. 项目目标
- **项目定位**：本科毕业设计项目。
- **项目名称**：基于 SpringBoot + Vue3 的宿舍报修与生活服务一体化系统。
- **最终要求**：结构规范、工程完整、具有一定亮点、能真实运行。

## 2. 核心系统功能（前后端分离，包含三种角色）
**【学生端】**
- **登录鉴权**：学号 + 密码登录，JWT认证。
- **宿舍报修**：楼栋 → 宿舍 → 故障类型三级结构联动；图片上传（OSS）；报修进度跟踪；服务评价。
- **生活服务预约**：洗衣房/吹风机预约；时段冲突检测；错峰推荐。
- **失物招领**：信息发布、分类筛选、认领功能。
- **二手交易**：分类发布、商品筛选、留言沟通、成交确认。
- **系统通知**：实时通知提醒。

**【维修员端】**
- **权限边界**：与学生权限严格区分。
- **工单管理**：接收派单、查看报修详情。
- **进度维护**：更新维修进度（如：已接单、维修中、已完成）。

**【管理员端】**
- **基础数据**：批量导入学生 / 宿舍信息。
- **内容合规**：审核违规内容。
- **资源管理**：维护服务资源（洗衣机、吹风机等基础数据）。
- **智能派单**：根据故障类型智能匹配对应的维修员。
- **数据看板**：多维度数据统计、数据筛选分析、柱状图 / 排行榜数据展示。

## 3. 企业级开发规范（强制实施）
在指导代码落地时，必须约束我使用以下规范：
- **分层架构**：`controller` / `service` / `serviceImpl` / `mapper` / `entity` / `dto` / `vo` 标准分层。
- **接口设计**：遵循 RESTful API 设计风格与接口文档规范。
- **基础封装**：统一返回结果封装（Result）、全局异常处理、统一日志规范。
- **安全性**：完善的参数校验机制。

## 关键决策

| 决策 | 原因 |
|------|------|
| 用 `el-select` 多选替代自由文本输入技能字段 | 12 种预设工种 + 支持自定义输入，管理员可不选让维修员自己填 |
| 个人中心做成独立页面而非弹窗 | 信息量大（编辑资料+密码+记录+统计），弹窗承载不了 |
| 记录区用 4 个 Tab + 懒加载 | 避免一次请求 4 个 API |
| `formatTime` 用正则而非 `new Date()` | Safari 不支持 `yyyy-MM-dd HH:mm:ss` 格式的 Date 构造 |
| JSON 序列化手动注册 JavaTimeModule | `WebMvcConfiguration extends WebMvcConfigurationSupport` 禁用了自动配置 |

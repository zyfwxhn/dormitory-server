## 二、核心流程 curl 测试命令

### A. 学生端 (Student)

#### A1. 登录 & 获取 Token
```bash
# 学生登录
curl -X POST $BASE_URL/student/login \
  -H "Content-Type: application/json" \
  -d '{"studentNo":"2024001","password":"123456"}'
# 预期: { "code":1, "data":{ "id":1, "name":"张三", "token":"..." } }
# 保存 token: export TOKEN="<token_value>"
```

#### A2. 获取个人信息
```bash
curl -X GET $BASE_URL/student/info -H "token:$TOKEN"
# 预期: { "code":1, "data":{ "studentNo":"2024001","name":"张三","buildingNo":"8","roomNo":"302" } }
```

#### A3. 提交报修 (核心流程)
```bash
curl -X POST $BASE_URL/student/repair/submit \
  -H "Content-Type: application/json" \
  -H "token:$TOKEN" \
  -d '{"repairType":"灯泡损坏","description":"测试报修-宿舍灯坏了"}'
# 预期: { "code":1, "msg":"..." }
```

#### A4. 查询我的报修 (分页+状态筛选)
```bash
curl "$BASE_URL/student/repair/page?page=1&pageSize=10" -H "token:$TOKEN"
curl "$BASE_URL/student/repair/page?page=1&pageSize=10&status=0" -H "token:$TOKEN"
```

#### A5. 评价已完成订单
```bash
curl -X POST $BASE_URL/student/repair/evaluate \
  -H "Content-Type: application/json" \
  -H "token:$TOKEN" \
  -d '{"id":4,"evaluationScore":5,"evaluationContent":"非常满意"}'
```

#### A6. 失物招领 — 发布
```bash
curl -X POST $BASE_URL/student/lost-found/publish \
  -H "Content-Type: application/json" \
  -H "token:$TOKEN" \
  -d '{"type":0,"title":"测试丢失钱包","description":"测试用","category":"校园卡","location":"图书馆","contactInfo":"13900001111"}'
```

#### A7. 二手商品 — 发布
```bash
curl -X POST $BASE_URL/student/secondhand-item/publish \
  -H "Content-Type: application/json" \
  -H "token:$TOKEN" \
  -d '{"name":"测试商品","description":"测试描述","category":"电子数码","price":99.99,"conditionLevel":"9成新"}'
```

#### A8. 二手留言
```bash
curl -X POST $BASE_URL/student/item-message \
  -H "Content-Type: application/json" \
  -H "token:$TOKEN" \
  -d '{"itemId":1,"toStudentId":1,"content":"测试留言"}'
```

#### A9. 生活预约
```bash
# 查可用时段
curl "$BASE_URL/student/reservation/available-slots?deviceId=1&reservationDate=2026-05-04" -H "token:$TOKEN"

# 提交预约
curl -X POST $BASE_URL/student/reservation/submit \
  -H "Content-Type: application/json" \
  -H "token:$TOKEN" \
  -d '{"deviceId":1,"reservationDate":"2026-05-04","startTime":"15:00:00","endTime":"16:00:00"}'
```

#### A10. 通知
```bash
curl $BASE_URL/student/notification -H "token:$TOKEN"
curl -X PUT $BASE_URL/student/notification/1/read -H "token:$TOKEN"
```

### B. 维修员端 (Worker)

#### B1. 登录
```bash
curl -X POST $BASE_URL/worker/login \
  -H "Content-Type: application/json" \
  -d '{"username":"worker01","password":"123456"}'
# 保存: export W_TOKEN="<token>"
```

#### B2. 工单状态流转 (接单→维修中→完工)
```bash
# 接单 (status:0→1)
curl -X PUT $BASE_URL/worker/repair/status \
  -H "Content-Type: application/json" \
  -H "token:$W_TOKEN" \
  -d '{"id":1,"status":1}'

# 开始维修 (status:1→2)
curl -X PUT $BASE_URL/worker/repair/status \
  -H "Content-Type: application/json" \
  -H "token:$W_TOKEN" \
  -d '{"id":1,"status":2}'

# 完工 (status:2→3, 必须传finishImages)
curl -X PUT $BASE_URL/worker/repair/status \
  -H "Content-Type: application/json" \
  -H "token:$W_TOKEN" \
  -d '{"id":1,"status":3,"finishImages":"https://example.com/photo1.jpg"}'
```

### C. 管理员端 (Admin)

#### C1. 登录
```bash
curl -X POST $BASE_URL/admin/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"123456"}'
# 保存: export A_TOKEN="<token>"
```

#### C2. 数据大盘
```bash

```

#### C3. 智能派单
```bash

```

#### C4. 设备管理
```bash
curl "$BASE_URL/admin/device/page?page=1&pageSize=10" -H "token:$A_TOKEN"
curl -X POST $BASE_URL/admin/device \
  -H "Content-Type: application/json" -H "token:$A_TOKEN" \
  -d '{"buildingNo":"8","deviceName":"新增测试设备","status":1}'
```

#### C5. 维修员管理
```bash
curl "$BASE_URL/admin/worker/page?page=1&pageSize=10" -H "token:$A_TOKEN"
curl -X PUT $BASE_URL/admin/worker/1/status/0 -H "token:$A_TOKEN"  # 停用
curl -X PUT $BASE_URL/admin/worker/1/status/1 -H "token:$A_TOKEN"  # 启用
```

#### C6. 内容审核
```bash
curl -X PUT $BASE_URL/admin/lost-found/violate \
  -H "Content-Type: application/json" -H "token:$A_TOKEN" \
  -d '{"id":1,"reason":"含违规内容"}'
```

## 三、安全测试用例

```bash
# 1. 无 Token 访问 (预期 401)
curl $BASE_URL/student/info

# 2. 伪造 Token (预期 401)
curl $BASE_URL/student/info -H "token:fake-token-12345"

# 3. 越权：学生 Token 访问维修员接口 (预期 401)
curl $BASE_URL/worker/info -H "token:$TOKEN"

# 4. 越权：学生取消他人报修单 (预期业务异常)
curl -X PUT $BASE_URL/student/repair/cancel/3 -H "token:$TOKEN"

# 5. 越权：学生评价他人订单 (预期业务异常)
curl -X POST $BASE_URL/student/repair/evaluate \
  -H "Content-Type: application/json" -H "token:$TOKEN" \
  -d '{"id":3,"evaluationScore":5,"evaluationContent":"越权测试"}'

# 6. SQL 注入测试
curl "$BASE_URL/student/repair/page?page=1&pageSize=10&status=0%20OR%201=1" -H "token:$TOKEN"
```

## 四、边界条件测试重点

| 接口 | 边界条件 |
|------|----------|
| POST /student/repair/submit | repairType 为空、description 超长、images 超 3 张 |
| POST /student/repair/evaluate | 评价非已完成订单、重复评价、score 超出 1-5 |
| PUT /student/repair/cancel/{id} | 取消已接单/已完成的订单 |
| POST /student/reservation/submit | 重复预约同一时段、预约过去日期、startTime >= endTime |
| PUT /worker/repair/status | 跳过状态流转(0→3)、完工不传 finishImages、抢已被接的单 |
| POST /admin/repair/dispatch/{id} | 对已派单的再派单、所有维修员都不在线 |
| POST /common/upload | 空文件、超大文件、非图片文件(.exe, .js) |

## 五、自动化测试建议

采用 **SpringBootTest + MockMvc + Testcontainers** 方案：

```
src/test/java/com/dormitory/dormitoryserver/
├── controller/
│   ├── StudentControllerTest.java    // 学生登录/信息接口
│   ├── RepairOrderControllerTest.java // 报修核心流程
│   ├── ReservationControllerTest.java // 预约冲突检测
│   └── SecurityTest.java             // 统一安全测试
└── service/
    ├── RepairOrderServiceTest.java    // 报修状态流转
    └── ServiceReservationTest.java    // 并发预约测试
```

**推荐测试框架：**
- `spring-boot-starter-test` (已有)
- `spring-security-test` (MockMvc)
- `com.h2database:h2` (内存数据库，测试用)
- `org.testcontainers:mysql` (可选，真实 MySQL 环境)

每个测试类覆盖：正常路径 + 异常路径 + 边界值 + 安全越权。
